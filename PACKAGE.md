# Weave

F# UI components for WebSharper. This is a release candidate; APIs may change.

The package embeds `styles.css` as a WebSharper resource and includes it as a NuGet content file. Link the extracted stylesheet in your HTML, or copy the content file to your application's static files and link it there.

See the [repository](https://github.com/1eyewonder/Weave) for documentation and tested WebSharper versions.
